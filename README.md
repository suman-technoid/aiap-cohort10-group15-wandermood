## What is WanderMood?
A mood-driven travel itinerary app. Pick how you feel, set your budget and duration, 
and get a complete personalised trip plan delivered to your inbox in under 60 seconds.

## Tech Stack
- Frontend: Bolt
- Backend: Supabase
- AI: OpenAI GPT-4o
- Orchestration: n8n
- Delivery: Gmail via n8n

## Moods
Unwind, Adventure, Romance, Party, Culture, Nature, Foodie, Solo Reset, Pick-me-up

## Folder Structure
- /frontend  : Bolt frontend code
- /n8n       : n8n workflow JSON
- /supabase  : Database schema SQL
- /docs      : Playbook and pitch deck
